# Tic-Tac-Toe Game in Python

## Description
A simple two-player Tic-Tac-Toe game developed using Python.

## Features
- Two-player gameplay
- 3×3 game board
- Win detection for rows, columns, and diagonals
- Draw detection
- Position validation

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run `python tic_tac_toe.py` in the terminal.
